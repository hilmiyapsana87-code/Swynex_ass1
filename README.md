🌎 Global YouTube Statistics 2023 — Data Analytics Case Study

📌 Project Overview

This project analyzes the Global YouTube Statistics 2023 dataset to explore channel performance, subscriber distribution, video views, content categories, geographical representation, and upload activity.

The project was completed as Task 4 of my Data Analyst Internship at SWYNEX Technologies. It demonstrates my ability to clean real-world datasets, perform exploratory data analysis, and communicate findings through data-driven insights.

🎯 Objectives

- Clean and prepare raw YouTube statistics data for analysis.
- Identify missing values, duplicate records, and data quality issues.
- Analyze channel performance using subscribers, views, and uploads.
- Explore content categories and geographical distribution.
- Present meaningful insights to support data-driven decision-making.

🛠️ Tools & Technologies

- Python — Data processing and analysis
- Pandas — Data cleaning and manipulation
- Jupyter Notebook / Google Colab — Code execution
- Microsoft Power BI — Dashboard visualization
- CSV — Dataset storage and export


🔍 Project Workflow

1. Data Loading — Imported the original dataset using Pandas.
2. Data Inspection — Examined dataset dimensions, column names, data types, and missing values.
3. Data Cleaning — Checked data quality issues and applied appropriate cleaning operations.
4. Data Validation — Compared the original and cleaned datasets to understand changes made during preprocessing.
5. Exploratory Data Analysis — Investigated channel performance, category trends, views, subscribers, and upload activity.
6. Dashboard Development — Used Power BI to present key performance indicators and visual insights.
7. Reporting — Documented the methodology, findings, and conclusions in a final case study.

📊 Key Analysis Areas

- 🏆 Top YouTube channels by subscribers
- 👀 Channel performance by video views
- 🎵 Content category comparison
- 🌍 Geographical distribution of channels
- 📤 Upload activity and publishing patterns
- 📈 Relationships between subscribers, views, and uploads

💡 Expected Business Value

This analysis can help content creators, digital marketers, and media analysts understand channel performance, compare content categories, and identify patterns in audience reach and publishing activity.
